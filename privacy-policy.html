Politique de Confidentialité

Dernière mise à jour : 2 janvier 2025

Lueur est une application mobile de géolocalisation qui vous permet d'explorer le monde et de révéler progressivement une carte personnelle. Nous prenons votre vie privée au sérieux.

1. Données collectées

Lueur collecte et stocke uniquement en local sur votre appareil les données suivantes :

  • Positions GPS : Vos coordonnées géographiques pour créer votre carte personnelle
  • Statistiques d'exploration : Distance parcourue, surface révélée, achievements débloqués
  • Préférences de l'application : Langue, paramètres d'affichage

2. Utilisation des données

Vos données GPS sont utilisées exclusivement pour :

  • Révéler les zones que vous avez explorées sur votre carte personnelle
  • Calculer vos statistiques (distance, surface, achievements)
  • Vous permettre d'exporter votre carte explorée

3. Stockage des données

Toutes vos données sont stockées localement sur votre appareil via SQLite. Nous n'utilisons aucun serveur externe, aucune base de données cloud, et nous ne transférons jamais vos données GPS vers des serveurs tiers.

4. Partage des données

Nous ne partageons AUCUNE de vos données avec des tiers, des annonceurs, ou des services externes. Vos explorations restent strictement privées.

5. Permissions demandées

L'application demande les permissions suivantes :

  • Localisation en arrière-plan : Pour continuer à enregistrer vos explorations même lorsque l'application est en arrière-plan
  • Notifications : Pour vous rappeler d'explorer si vous êtes inactif pendant plusieurs jours (optionnel)
  • Stockage : Pour exporter votre carte en image PNG (optionnel)

6. Suppression des données

Vous pouvez supprimer toutes vos données à tout moment via les paramètres de l'application (section "Données" > "Réinitialiser les données"). Cette action est irréversible.

Désinstaller l'application supprime également automatiquement toutes les données stockées localement.

7. Sécurité

Vos données sont protégées par les mécanismes de sécurité de votre système d'exploitation (Android/iOS). Nous n'avons pas accès à vos données car elles ne quittent jamais votre appareil.

8. Modifications de cette politique

Nous pouvons mettre à jour cette politique de confidentialité. Toute modification sera publiée sur cette page avec une nouvelle date de "Dernière mise à jour".

9. Hébergement de cette page

Cette politique de confidentialité est hébergée sur GitHub Pages. Conformément à la politique de GitHub Pages, votre adresse IP est enregistrée à des fins de sécurité lors de votre visite de cette page.
